# 🇰🇭 ប្រព័ន្ធគ្រប់គ្រងសាលារៀនគ្រប់ជ្រុងជ្រោយ (Cambodia School Management System — Enterprise ERP)

ប្រព័ន្ធគ្រប់គ្រងសាលារៀនឌីជីថលកម្រិតខ្ពស់ (**Full-Stack SQLite + Offline PWA Hybrid**) សម្រាប់សាលាចំណេះទូទៅ និងសាលាឯកជនអន្តរជាតិ (មត្តេយ្យសិក្សា បឋមសិក្សា អនុវិទ្យាល័យ និងវិទ្យាល័យ K–12) តាមស្តង់ដារក្រសួងអប់រំ យុវជន និងកីឡា (**MoEYS Cambodia**)។

---

## ✨ មុខងារធំៗទាំង ១៣ (13 Integrated Enterprise Modules)

1. **ផ្ទាំងគ្រប់គ្រងរួម (Executive & Role-Based Dashboard)** — ទិដ្ឋភាពរួមនៃសិស្ស គ្រូ វត្តមាន ចំណូល-ចំណាយ ការបែងចែកនិទ្ទេស MoEYS (A–F) និងតារាងកិត្តិយស។
2. **ប្រព័ន្ធគ្រប់គ្រងព័ត៌មានសិស្ស (Student Information System & 360° Profile)** — ចុះឈ្មោះសិស្ស បង្ហោះរូបថត ប្រវត្តិរូប ៣៦០° ព័ត៌មានអាណាព្យាបាល ដំឡើងថ្នាក់សិស្ស និង **ប័ណ្ណសម្គាល់ខ្លួនសិស្សមានកូដ QR**។
3. **រចនាសម្ព័ន្ធសិក្សា ថ្នាក់រៀន និងមុខវិជ្ជា (Academic K–12 & Curriculum)** — មត្តេយ្យ បឋម អនុ និងវិទ្យាល័យ (វិទ្យាសាស្ត្រ/សង្គម) និងការកំណត់ពិន្ទុអតិបរមា/មេគុណមុខវិជ្ជា។
4. **ធនធានមនុស្ស គ្រូបង្រៀន ច្បាប់ឈប់សម្រាក និងប្រាក់បៀវត្សរ៍ (HR, Leaves & Payroll)** — បញ្ជីបុគ្គលិក អនុម័តច្បាប់ឈប់សម្រាក គណនាប្រាក់ខែប្រចាំខែ និងបោះពុម្ពសន្លឹកប្រាក់ខែ (**Payslip**)។
5. **កាលវិភាគសិក្សាប្រចាំសប្តាហ៍ (Interactive Timetable)** — មើលតាមថ្នាក់រៀន ឬតាមគ្រូបង្រៀន (ចន្ទ–សៅរ៍) ជាមួយប្រព័ន្ធការពារជាន់ម៉ោងស្វ័យប្រវត្តិ។
6. **វត្តមានសិស្ស និងម៉ាស៊ីនស្កេន QR (Attendance & QR Gate Scanner)** — កត់ត្រាវត្តមានប្រចាំថ្នាក់ (P/A/L/E) ស្កេនកាតសិស្សរហ័ស និងបញ្ជីតាមដានសិស្សអវត្តមានច្រើន (<88%)។
7. **ប្រព័ន្ធពិន្ទុ ចំណាត់ថ្នាក់ និទ្ទេស A–F និងប្រឡង (MoEYS Gradebook & Exams)** — បញ្ចូលពិន្ទុជាក្រុម តារាងចំណាត់ថ្នាក់រួមប្រចាំថ្នាក់ តារាងកិត្តិយស Top 5 និងកាលវិភាគប្រឡង។
8. **កិច្ចការផ្ទះ និងការតាមដានវិន័យសិស្ស (Homework & Behavior/Merits)** — ដាក់កិច្ចការផ្ទះតាមថ្នាក់ និងកត់ត្រាបណ្ណសរសើរ/ការណែនាំវិន័យ។
9. **ហិរញ្ញវត្ថុ ថ្លៃសិក្សា អាហារូបករណ៍ និងវិក្កយបត្រ KHQR (Tuition, KHQR & Accounting)** — ចេញវិក្កយបត្រតាមថ្នាក់ស្វ័យប្រវត្តិ គណនាអាហារូបករណ៍ ទទួលប្រាក់តាម ABA KHQR/Cash (USD & KHR `៛`) បង្កាន់ដៃផ្លូវការ និងកំណត់ត្រាចំណាយសាលា។
10. **បណ្ណាល័យឌីជីថល (Library & Book Circulation)** — បញ្ជីសៀវភៅ ការខ្ចី និងការសងសៀវភៅ។
11. **សេចក្តីជូនដំណឹង និងប្រតិទិនឆ្នាំសិក្សា (Announcements & Calendar)** — ផ្សព្វផ្សាយដំណឹងសាលា និងថ្ងៃបុណ្យជាតិ/កម្មវិធីសិក្សា។
12. **មជ្ឈមណ្ឌលបោះពុម្ពរបាយការណ៍ផ្លូវការ A4 PDF & Excel CSV (Print Studio & Exports)** — ទម្រង់ឯកសារផ្លូវការមានបាវចនា `ព្រះរាជាណាចក្រកម្ពុជា · ជាតិ សាសនា ព្រះមហាក្សត្រ` និងការនាំចេញ CSV គាំទ្រអក្សរខ្មែរ UTF-8 BOM។
13. **ការកំណត់ប្រព័ន្ធ បម្រុងទុក JSON និងកំណត់ហេតុសុវត្ថិភាព (Settings, Backup & Audit Logs)**។

## 🚀 របៀបដំណើរការគម្រោង (Quick Start)

```bash
# 1. ដំឡើងកញ្ចប់បណ្ណាល័យ (Install dependencies)
npm install

# 2. បង្កើត Production Build សម្រាប់ Frontend + PWA
npm run build

# 3. ដំណើរការម៉ាស៊ីនមេរួម Full-Stack (Express API + SQLite + Frontend លើ Port 3000)
npm start
```

សម្រាប់ការអភិវឌ្ឍកូដផ្ទាល់ (Development Mode):
```bash
npm run dev:api   # Backend Express + SQLite API on 127.0.0.1:3001
npm run dev:web   # Vite React HMR on 0.0.0.0:5173
```

> **Hybrid Architecture**: ប្រសិនបើអ្នកបង្ហោះថត `dist/` លើ Static Hosting (ឧ. GitHub Pages / Netlify) ដោយគ្មាន Backend Server ប្រព័ន្ធនឹងប្តូរទៅដំណើរការជា **Offline PWA Local Database** ដោយស្វ័យប្រវត្តិ ១០០%!
